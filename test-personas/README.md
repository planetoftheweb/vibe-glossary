# Test personas

Six fictional learners for testing VibeGlossary's accounts, progress sync, scoring,
and (eventually) an admin screen. Each has a personality file in this folder and a
machine-readable fixture in [personas.json](personas.json).

**Everything here is fictional.** Emails use `@example.com`, the shared password
(`vibetest123!`) is a fixture, not a secret, and no accounts exist in Firebase yet —
seeding requires Authentication to be enabled in the console first.

## What's in each file

- **Personality** — who they are, why they're learning, how they behave in the app.
- **Account form data** — what they typed at signup (or got from Google).
- **Progress summary** — what they've visited, copied, and mastered, with the
  exact expected VibeScore breakdown computed by `src/lib/scoring.js`.

## How to use them

- **Manual testing today:** open the app in a private window, use the persona's
  progress as a script ("visit these, copy those"), and check the expected readout.
- **Seeding later:** once Firebase Auth is enabled, `personas.json` has the exact
  `users/{uid}` document shape (`snapshot` matches `makeSnapshot()` in
  `src/lib/cloudSync.js`) so a seed script can create the accounts and back-fill
  their progress docs.
- `attempts` and `retention` are intentionally empty: they're generated by real
  quiz interactions and the scoring here already assumes the passes they imply.

Scores were computed with the app's real scoring code on 2026-08-17
(98 glossary + 125 build topics). Adding topics later won't break these fixtures;
scores only grow if the personas "do" more.
